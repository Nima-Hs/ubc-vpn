The Microsoft C runtime in ubc-vpn.exe and ubc-vpn-service.exe
==============================================================

The command-line client (ubc-vpn.exe) and the service (ubc-vpn-service.exe)
are built with the Microsoft Visual C++ toolset and have Microsoft's C
runtime linked into them (Rust's +crt-static), so they need no Visual C++
Redistributable. The runtime parts linked in are:

- the Visual C++ runtime (vcruntime) and C startup code, from the static
  libraries libvcruntime.lib and libcmt.lib of the MSVC toolset;
- the Universal C Runtime (UCRT), from the static library libucrt.lib of
  the Windows 10/11 SDK.

They are Microsoft's code, not ours and not open source. They are used and
redistributed, as part of programs built with them, under:

- the Microsoft Software License Terms for Visual Studio, including its
  terms for Distributable Code (https://aka.ms/vs/18/redistribution and
  https://visualstudio.microsoft.com/license-terms/);
- the Microsoft Software License Terms for the Windows SDK.

Where the source comes from: both are installed with the tools that build
these programs. The Visual C++ runtime's source is in the MSVC toolset, in
VC\Tools\MSVC\<version>\crt\src of a Visual Studio or Build Tools
install. The UCRT's source is in the Windows SDK, in
Windows Kits\10\Source\<version>\ucrt. The versions used for a release are
those of the build machine, recorded by the release build.
