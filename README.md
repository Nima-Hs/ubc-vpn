# UBC VPN

A split-tunnel client for UBC's myVPN. Only the UBC subnets you choose go through the VPN; all other traffic stays on your normal connection.

Targets Windows, Linux, and macOS.

> Early development: there is no usable release yet.

See [CONTRIBUTING.md](CONTRIBUTING.md) for setup and workflow.
